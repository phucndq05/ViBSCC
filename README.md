# ViBSCC

**ViBSCC: A Vietnamese Online Comment Corpus for Direct and Indirect Body-Shaming Detection**

ViBSCC is a human-annotated Vietnamese corpus for three-way body-shaming detection. The corpus contains 6,595 online comments collected from Facebook, YouTube, TikTok, and VnExpress, and distinguishes non-shaming, indirect/sarcastic body-shaming, and direct/offensive body-shaming.

## Dataset Overview

- **Language:** Vietnamese
- **Size:** 6,595 comments
- **Sources:** Facebook, YouTube, TikTok, and VnExpress
- **Annotation:** Human annotated
- **Task:** Three-way body-shaming detection
  - Non-shaming
  - Indirect / Sarcastic
  - Direct / Offensive

## Dataset Access

ViBSCC is available for research purposes. The raw dataset is not distributed directly through this public repository.

Access to ViBSCC requires completion of the ViBSCC User Agreement. Researchers interested in accessing the dataset should contact the corresponding author at **tinhv@uit.edu.vn**.

Dataset requests are reviewed before access instructions are provided.

The approved ViBSCC User Agreement will be added to this repository separately.

## Intended Use

ViBSCC is intended for academic and research use, including research on Vietnamese natural language processing, body-shaming detection, offensive language detection, and human-in-the-loop moderation.

The dataset is not intended for deanonymization, profiling of individuals, surveillance, automated punishment, harassment, or generation of abusive content.
